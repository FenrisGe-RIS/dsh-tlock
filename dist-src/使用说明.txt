T约束（dsh-tlock）· 使用说明
========================================

这是个 DeepSeek Harness（DSH）插件：给每一轮生成装一个「刹车」——
token 到量就断、时间到点就断，断下来的内容自动存到桌面。


一、装（Windows）
----------------------------------------
1. 把整个文件夹解压到任意位置（别直接在压缩包里双击）。
2. 双击「安装.bat」。
   - 想先看它打算干什么：在 PowerShell 里执行
     powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1 -DryRun
3. 看到「装好了」之后，**完全退出 DSH 再重新打开**（不是最小化，要退干净）。
4. 打开 DSH，页面右下角会出现一颗黑色方块悬浮球 —— 点它。


二、用
----------------------------------------
· 打开悬浮球 → 「约束模式」→ 拉两条滑条：
    - Token 上限：5 千 ~ 100 万 / 轮（拖到刻度会吸附，也可以点「手动输入」）
    - 时间上限：1 分钟 ~ 2 小时 / 轮（从你按下发送开始算，跑工具的时间也算）
· 到 80% / 90% 会先问你「还接着生成吗」；到 100% 直接硬断。
· 断下来的内容会自动存到：

    桌面\DSH限定生成内容\{token限定版 | 时间限定版 | 手动结束}\时间_会话名\

  文件有两种口味（面板里选）：
    - 简洁描述：生成说明.md，人看一眼就知道这轮写了什么
    - AI联动分析：AI联动分析.md，完整思考 + 代码，可以整份粘给你自己的模型
· 不想留档就点「解除归档」——照样硬断，只是不写文件。
· 「查看历史归档记录」页能翻所有存档。

· 面板可以拖标题栏移动；关面板点右上角 ✕ 或点空白处。
· 设置页：插件开关、悬浮球开关、开机自启、页面大小、语言（中文 / English）。


三、可选：桌面控制台
----------------------------------------
安装脚本会把 TLock.exe 放到：
    %LOCALAPPDATA%\TLock\TLock.exe

双击它，托盘会常驻一个小图标，不打开 DSH 也能改限额、开归档目录。
它和 DSH 里的面板共用同一份设置，改哪边都一样。


四、设置存在哪
----------------------------------------
    %USERPROFILE%\.dsh\storages\dsh-tlock\
        settings.json   你的限额与开关
        status.json     当前进度（插件写）
        history.json    归档清单
删掉整个目录 = 恢复默认，不影响 DSH 本身。


五、卸
----------------------------------------
1. 关掉 DSH 和 TLock.exe。
2. 打开你的 profile 目录（一般是 %USERPROFILE%\.dsh\profiles\desktop\）：
   - 删掉 node_modules\dsh-tlock
   - 打开 package.json，把 dependencies 里的 "dsh-tlock" 和
     dsh.profile.bundles 里的 "dsh-tlock" 删掉
3. 想清干净再删 %USERPROFILE%\.dsh\plugins\dsh-tlock 和
   %USERPROFILE%\.dsh\storages\dsh-tlock，以及 %LOCALAPPDATA%\TLock。


六、常见问题
----------------------------------------
Q: 点安装.bat 一闪就没了？
   用 PowerShell 手动跑 install.ps1，能看到具体报错。

Q: 提示找不到 profile？
   先打开一次 DSH 让它把 profile 建出来，再装。

Q: 装了但右下角没有悬浮球？
   - 确认是「完全退出 DSH 再开」，不是刷新窗口；
   - 有些版本要刷新页面（Ctrl+R）才加载客户端；
   - 看 %USERPROFILE%\.dsh\storages\dsh-tlock\status.json 有没有在更新，
     有更新说明后端已经跑起来了。

Q: 会不会影响我原来的对话？
   不会。它只读会话事件算用量、在到量时调一次中断，再写归档文件。
   不改你的输入，不动模型输出。

Q: 支持 Mac / Linux 吗？
   插件本体（lib/*.js）是纯 Node 代码，理论上跨平台；
   但安装脚本和桌面控制台是 Windows 的。
